# Compatibility

The current dedicated core is `1.4.4-rc.1`. It is a Windows-focused Codex plugin and is validated by the sealed source regression suite and release-integrity checks for the candidate revision.

The repository does not promise compatibility with every Codex desktop build, provider, terminal, security product, or Windows configuration. A final release requires fresh clean-machine and remote GitHub marketplace acceptance bound to the final ref.

Historical machine matrices and local rollout records are deliberately excluded from the public release evidence because they cannot certify the current candidate.
